# X-Ray Online

Открытый сервер сетевой игры для движка OpenXRay: один процесс обслуживает
«Тень Чернобыля», «Чистое Небо» и «Зов Припяти». Он заменяет закрытые сервисы
GameSpy/GSC, которых больше нет.

| Сервис | Порт | Протокол | Для чего |
|---|---|---|---|
| Мастер-сервер | 28910 | TCP + UDP | Список серверов всех трёх игр: игровые серверы регистрируются (UDP), клиенты получают список (TCP) |
| GP connection manager (gpcm) | 29900 | TCP | Вход в аккаунт, смена ника, удаление профиля (сетевая игра «Зова Припяти») |
| GP search manager (gpsp) | 29901 | TCP | Регистрация аккаунта из игры, ники по e-mail, подсказка свободного ника |
| Веб-интерфейс | 8080 | HTTP | Список серверов, регистрация, админка (статистика, аккаунты, баны, настройки), JSON API |

Мастер сам опрашивает каждый игровой сервер по GameSpy QR2, поэтому на сайте и
в админке видны название, карта, режим, игроки и пинг.

## Что нужно серверу

- Любой Linux/Windows с **Python 3.9+**. Сторонних библиотек нет: только
  стандартная библиотека и встроенная SQLite.
- Публичный IPv4 (или проброшенные порты), открытые **28910/tcp, 28910/udp,
  29900/tcp, 29901/tcp** и порт веб-интерфейса.
- Ресурсов почти не нужно: на сотни серверов и тысячи аккаунтов хватит самой
  маленькой VPS (1 vCPU, 512 МБ ОЗУ).
- Для сайта снаружи лучше поставить перед веб-портом HTTPS-прокси (nginx,
  Caddy) и открыть наружу только его.

Игровые серверы (хосты матчей) сервер не запускает: их по-прежнему поднимают
игроки или вы сами, движком с ключом `-dedicated` или из меню игры. Сервер
только сводит их с клиентами и ведёт аккаунты.

## Запуск

```bash
cd online
python -m xray_online init --config xray-online.ini      # создаст конфиг и спросит пароль админа
python -m xray_online run --config xray-online.ini
```

Конфиг (`[server]`): адреса и порты, путь к базе, `secret` для подписи
сессий админки и хеш пароля администратора. Пароль меняется командой
`python -m xray_online set-admin-password --config xray-online.ini`.

Пример systemd-юнита:

```ini
[Unit]
Description=X-Ray Online
After=network-online.target

[Service]
WorkingDirectory=/opt/xray-online/online
ExecStart=/usr/bin/python3 -m xray_online run --config /opt/xray-online/xray-online.ini
Restart=always
User=xray

[Install]
WantedBy=multi-user.target
```

## Подключение игры

В лаунчере Android-порта в профиле укажите адрес сервера в поле
«Мастер-сервер GameSpy» (порт 28910). Движок тогда берёт список серверов
отсюда, регистрирует запущенные матчи здесь и, для «Зова Припяти», входит в
аккаунт на этом же адресе (порты 29900/29901). Аккаунт создаётся в игре или
на сайте `/register`.

## Безопасность

Протокол входа GameSpy требует, чтобы сервер знал `md5(пароль)`: без него он
не может проверить ответ клиента. Поэтому, кроме стойкого PBKDF2-хеша для
сайта, база хранит MD5 пароля. Предупреждайте игроков не использовать
пароли от других сервисов, и закрывайте файл базы от чужих глаз.

Админка защищена паролем (PBKDF2), подписанной cookie с ограниченным сроком
и CSRF-токеном на всех изменяющих действиях.

## Разработка

```bash
python -m unittest discover -s tests
```

Тесты поднимают все сервисы на свободных портах и ведут себя как клиент
движка: регистрируют серверы, создают аккаунт, входят с проверкой `proof`,
меняют ник, ищут ники, работают с админкой. Кодирование пароля сверено с
`gpiEncodeString` из SDK (`Externals/GameSpy/src/GameSpy/GP`).

  heartbeat), чтобы к этому же серверу подключались неизменённые клиенты на
  ПК. Сейчас список серверов работает по простому протоколу OpenXRay.
- Друзья, личные сообщения и статистика игроков (ATLAS).
